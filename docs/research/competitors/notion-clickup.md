# Competitor research: Notion and ClickUp (vs MorrowList) — 2026-09-02

Scope: Notion databases (Board view, Projects/Tasks/Sprints templates, Notion AI/Agents) and ClickUp (Board view, 4.0, Brain). Both treat Kanban as one view over a database of records. Claims below are sourced; anything not verified from a source is marked _unverified_.

## 1. Product snapshots

**Notion.** Doc/database-centric all-in-one workspace; strongest with knowledge workers, solo users and small teams doing notes + light PM. Plans: Free ($0; buttons-only automations, 10 guests, 5 MB uploads), Plus ($10/user/mo annual, $12 monthly; database automations, webhooks), Business ($20 annual / $24 monthly; full Notion AI + Agent, custom automations, dashboards), Enterprise (custom) [pricing](https://www.notion.com/pricing). Custom Agents cost $10 per 1,000 credits on top of Business/Enterprise (same page). Scale: ~100M users (milestone Sept 2024), ~4M paying customers, ~$600M revenue Dec 2025, $11B tender in Jan 2026 [super.so](https://super.so/blog/notion-stats), [sqmagazine](https://sqmagazine.co.uk/notion-statistics/) (secondary sources; company has not published a 2026 count). Capterra 4.7/5 on 2,808 reviews [Capterra](https://www.capterra.com/p/186596/Notion/reviews/).

**ClickUp.** Task/ops-centric "converged AI workspace" (tasks + docs + chat + whiteboards); strongest with agencies, ops and cross-functional teams. Plans: Free Forever (unlimited tasks/members, 60 MB storage, 5 automation rules/100 runs), Unlimited ($7/user/mo annual, $10 monthly), Business ($12 annual / $19 monthly), Enterprise (custom); AI is a separate per-seat add-on: Brain AI $9/user/mo, Everything AI $28/user/mo [pricing](https://clickup.com/pricing). Scale: $300M ARR, 20M+ users, 800k+ team signups/month, AI usage +800% YoY (company press release, 9 Sep 2025) [Yahoo Finance](https://finance.yahoo.com/news/clickup-accelerating-300-million-annual-130000796.html). G2 4.7/5 on 10,000+ reviews [G2](https://learn.g2.com/clickup-review); Capterra 4.6/5 on 4,622 [Capterra](https://www.capterra.com/p/158833/ClickUp/reviews/). ClickUp 4.0 shipped 12 Dec 2025 (new global nav, Home/My Tasks, Teams Hub, ambient AI agents, Planner) [TechRepublic](https://www.techrepublic.com/article/news-clickup-ai-overhaul/).

## 3. Gaps MorrowList should consider

**Table-stakes** (every Kanban tool at this level has them; users expect them on day one):

- **Group board by other properties + swimlanes (#1–2).** Both let users pivot the same tasks by priority/assignee/due; ClickUp's subgroup grid is standard for "who is doing what at which stage." Cheap for ML because the board already projects one task model; group-by priority/due bucket/project needs no schema change.
- **Hide/collapse columns and per-view card fields (#4–5).** Notion's "Hide group" and ClickUp's card customize menu are the basic decluttering controls.
- **Subtasks UI and dependencies (#13–14).** Schema exists; both products ship these free. ClickUp shows subtasks as cards or nested; Notion filters parents vs sub-items. Blocked-by is directly visible to ML's "Blocked" column.
- **Recurring tasks (#15).** Free in both; personal task managers without recurrence lose habit/routine use cases. Keep it simple (RRULE-ish daily/weekly/monthly/yearly + interval as Notion does) rather than ClickUp's many options.
- **Saved views and filter UI (#27–28).** Notion's per-view filter/sort/group with personal vs shared save is the model; ML already has URL-param filters, so named saved views are a thin layer.
- **Search (#34), calendar (#21), export (#42).** All three are Free-tier in both products. Markdown+CSV/JSON export matters for the self-host/lock-in story (see §4).

**Differentiators** (where ML can stand out given its persona and architecture):

- **Offline-first (#43).** Neither is truly offline: Notion is app-only, first 50 DB rows, no web; ClickUp cannot even edit tasks offline. Capterra reviewers still say Notion has "no offline access". A PWA with a local task cache and ML's existing optimistic/409 concurrency would beat both.
- **Fast, small data model instead of "everything is a database".** Reviewers document Notion slowing at 5,000+ rows (3–5 s loads) and ClickUp "lag in creating tasks". A fixed, indexed task model is a feature; do not copy custom fields wholesale.
- **Webhooks/agent access (#37–39).** Notion gates webhooks to Plus+, ClickUp to Business+. ML already has outbox events; delivering them plus a documented CLI/MCP path is free-tier differentiation.
- **Lightweight tags + custom fields (#10).** Consider tags and 2–3 typed fields (select/number/date) rather than 20 property types.

**Nice-to-have:** column calculations (#8), card covers (#3), task templates (#16), bulk actions (#9), activity UI (#33), keyboard palette + slash commands (#35), global quick-capture hotkey (#36), basic AI summarize/autofill via user-supplied key (#45).

**Niche for ML's persona:** workload/capacity (#25), dashboards (#26), sprints/velocity (#50), goals (#51), time tracking (#49), task types (#17), multi-model AI agents (#46–48), forms (#57), row permissions (#56). These are team/ops features; ClickUp's own 4.0 reviewer says the AI Planner "doesn't understand dependencies; wildly optimistic timeframes" — do not chase it.

**What not to copy:** ClickUp's feature density ("buttons everywhere, sidebars, menus, settings, tabs"; 1–2 weeks of "where did everything go?" after 4.0), notification overload, hotkeys off by default, and AI as a $9–$28/seat add-on with credit tracking. Notion's automations "cannot trigger other automations", 3-second change detection window, and paid gating of basic offline auto-download are also friction points.

## 4. What users complain about (opportunities)

- **Performance at scale.** Notion: "3-5 second delay once CRM crossed 5,000+ contacts" [Hack'celeration](https://hackceleration.com/notion-review/); "Larger pages can take a few seconds to load" [Capterra](https://www.capterra.com/p/186596/Notion/reviews/). ClickUp: performance/reliability rated 2/5, "slow sometimes, especially when using the whiteboards" [Business Dive](https://thebusinessdive.com/clickup-review); "Lag in creating tasks" [Capterra](https://www.capterra.com/p/158833/ClickUp/reviews/); custom-field clutter "slow[s] down load times" [WMH](https://workmanagementhub.com/clickup-review-2026/).
- **Bloat / learning curve.** ClickUp: "learning curve is incredibly steep… very overwhelming", "way too busy" (Capterra); "overwhelming… buttons everywhere" [G2](https://learn.g2.com/clickup-review). Notion: "2+ weeks" to learn advanced features (Hack'celeration); "spending more time trying to figure out how to do simple things" (Capterra).
- **Offline.** Notion: "Cannot create new pages or complex blocks offline" (Hack'celeration; partially outdated since Aug 2025, but web still has none); "No true offline access (downloaded pages only)" [Business Dive](https://thebusinessdive.com/notion-review). ClickUp: cannot edit tasks or create subtasks offline (help center).
- **Mobile.** Notion: "Editing databases on mobile is frustrating", Android lag/crashes (Hack'celeration, Capterra). ClickUp: mobile 6/10, SyncUps "still buggy on mobile" (ZenPilot); "not so useful as the desktop app" (Capterra).
