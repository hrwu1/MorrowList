# Open-source / self-hosted Kanban & task tools vs MorrowList

Research date: 2026-09-02. GitHub numbers pulled live via the GitHub API on that date. Reddit could not be fetched from this environment, so "complaints" are sourced from GitHub issues, project forums, and independent blog comparisons.

Abbreviations: PL=Planka, WK=WeKan, KB=Kanboard, FB=Focalboard, VK=Vikunja, TG=Taiga, OP=OpenProject, LT=Leantime, HU=Huly, ND=Nextcloud Deck. Pro = paid tier only.

## 3. Gaps MorrowList should consider

Ratings: **T** = table-stakes, **D** = differentiator, **N** = nice-to-have, **X** = niche.

| Gap                                              | Why self-hosters value it (evidence)                                                                                                                                                                        | Rating                      |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| Labels/tags + subtask/checklist UI               | Present in every competitor; Vikunja's #336 "Simplify adding subtasks" (11 reactions) shows even incumbents get it wrong                                                                                    | T                           |
| Column editing (add/rename/reorder/color)        | Baseline of every tool; Kanboard homepage leads with it                                                                                                                                                     | T                           |

## 4. What users complain about — opportunities

- **Planka**: license flip to non-OSI "fair-code" at 2.0; in v2.2.0 "OIDC/SSO has been removed from PLANKA Community… all SSO-based users are deactivated" ([release](https://github.com/plankanban/planka/releases/tag/v2.2.0)); custom fields, templates, calendar, recurring, time tracking, full mobile, export all Pro-gated ([Community page](https://planka.app/community)); Postgres-only ([#270](https://github.com/plankanban/planka/issues/270)); mobile issue open since 2020 ([#19](https://github.com/plankanban/planka/issues/19)); kanban-only, no export ([Vikunja compare](https://vikunja.io/compare/planka/)). → Opportunity: stay genuinely open, ship the "Pro" list for free.
- **WeKan**: upgrades break production — v9.95 "400% CPU… 10 minutes before I can see my boards" ([#6468](https://github.com/wekan/wekan/issues/6468)), snap auto-update broke ([#6471](https://github.com/wekan/wekan/issues/6471)), YunoHost upgrade failures ([forum](https://forum.yunohost.org/t/update-wekan-wekan-from-7-94-ynh1-to-8-32-ynh1-failed/41590)); UI regressions ("looks like a samsung smartphone UI", SSO/labels regressions, [Vikunja compare](https://vikunja.io/compare/wekan/)); MongoDB, ~500 MB RAM; "GitHub issues/PRs are only for FLOSS Developers, not for support" ([README](https://github.com/wekan/wekan)). → Opportunity: boring, tested releases; migrations that don't break.
- **Kanboard**: "maintenance mode" ([README](https://github.com/kanboard/kanboard)); no real-time updates, "basic mobile responsiveness", minimalist/dated UI ([pistack](https://www.pistack.xyz/posts/self-hosted-kanban-boards-guide/)); official CLI unmaintained ([kanboard-cli](https://github.com/kanboard/kanboard-cli)); reverse-proxy/subpath pain ([#4119](https://github.com/kanboard/kanboard/issues/4119)). → Opportunity: Kanboard's feature depth (automation, analytics, links, recurring) in a modern, mobile UI with a maintained CLI.
- **Focalboard**: unmaintained; users "switching to Planka after Focalboard converted to community support" ([alternativeto](https://alternativeto.net/software/planka/about)); 730 open issues. → Displaced users looking for a home with table/calendar views and properties.
- **Vikunja**: CalDAV "early alpha stage and has bugs", no Thunderbird/iOS ([docs](https://vikunja.io/docs/caldav/)); no live sync ([#1460](https://github.com/go-vikunja/vikunja/issues/1460)); no custom fields; subtasks clunky; no calendar view; webhooks have "no retry mechanism" ([docs](https://vikunja.io/docs/webhooks/)). → Closest positioning to MorrowList (personal-first, multiple views of one model, API, CalDAV) — MorrowList must match its views and beat it on polish/CLI.
- **Taiga**: "Activity has slowed", community worried about abandonment, "lack of communication on our parts" ([thread](https://community.taiga.io/t/state-of-taiga-as-a-whole/3831)); Taiga Next left to become Tenzu; AngularJS front end. → Agile-team tool, not a personal competitor.
- **OpenProject**: action boards, team planner, OIDC/SAML are Enterprise-only ([pricing](https://www.openproject.org/pricing/)); heavy Rails stack. → Overkill for individuals.
- **Leantime**: whole-PM-suite scope; premium AI; PHP/MySQL ([README](https://raw.githubusercontent.com/Leantime/leantime/master/README.md)). Its ADHD/neurodivergent framing and "My Work" dashboard are worth borrowing.
- **Huly**: minimum "2 vCPUs and 8 GB RAM", recommended 16 GB; CockroachDB + Elasticsearch + MinIO + Redpanda + ~10 services; "slightly more than 35 GB" disk for a dev build; hosted service discontinued for lack of funding ([selfhost](https://github.com/hcengineering/huly-selfhost), [README](https://raw.githubusercontent.com/hcengineering/platform/develop/README.md)). → Opportunity: "one container + Postgres" simplicity.
- **Nextcloud Deck**: "Deck is not yet ready for intensive usage" — 13 boards × 100 cards × 5 attachments ≈ 6,500 DB queries per load ([README](https://github.com/nextcloud/deck)); requires a full Nextcloud. → Opportunity: performance at scale, standalone.

Cross-cutting patterns from comparisons ([pistack](https://www.pistack.xyz/posts/wekan-vs-kanboard-vs-planka-self-hosted-kanban-guide-2026/), [homelabcompass](https://homelabcompass.com/alternatives/self-hosted-alternative-to-trello), [virola](https://virola.io/articles/top-self-hosted-kanban-boards)): self-hosters rank tools by (1) RAM footprint and DB choice, (2) UI modernity, (3) whether the project is alive, (4) license purity, (5) mobile. No competitor has a first-party, maintained CLI — third-party Planka CLIs explicitly target "AI agents", a signal MorrowList's CLI/API-first design is on-trend.
